# ФинКонтроль — Android

Нативное Android-приложение для личных финансов. Доходы, расходы, кредитные платежи, цели, аналитика и рекомендации.

Все стартовые числа — демонстрационные. Финансовые данные сохраняются локально на устройстве.

## Скачать APK
Откройте вкладку **Actions**, выберите успешную сборку **Build Android APK**, внизу скачайте артефакт **FinControl-APK**. В архиве будет файл `app-debug.apk`.

## Сборка
Открыть проект в Android Studio либо использовать бесплатную автоматическую сборку GitHub Actions. Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Android SDK 35.

Android package: `ru.finkontrol.app`.
